# Benedikt Stemmildt

Founder & Co-CEO of [hackers&wizards](https://www.hackersandwizards.dev) in Hamburg. We train and mentor engineering and product teams in agentic engineering, hands-on, on their own code and in the coding agent they already use.

I have built software for twenty years: engineer at OTTO, architect at Breuninger, CIO at BLUME 2000, CTO at TalentFormation. I have worked with coding agents since the first tools came out at the end of 2022.
